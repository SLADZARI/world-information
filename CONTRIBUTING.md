# Contributing to World Information

Contributions are welcome in Russian or English. Research is reviewed for evidence quality, not ideological agreement.

## Propose an analysis

1. Open an Issue describing an event, question, or observed anomaly.
2. Fork the repository (or create a branch if you have write access).
3. Copy `templates/story.md` to `stories/YYYY/YYYY-MM-DD-short-slug.md`.
4. Link primary sources and datasets, with publication and access dates. Check that redistribution is permitted.
5. Clearly mark **observations**, **hypotheses**, **alternative explanations**, **forecast**, and **what would falsify the claim**.
6. Submit a Pull Request with a short summary and links to evidence. Authors remain responsible for corrections.

## Review checklist

- [ ] Specific event, time window, region, and units
- [ ] Claims trace to primary evidence or clearly labeled secondary reports
- [ ] Publication time is not confused with event time
- [ ] No unsupported causal inference or invented probability
- [ ] Alternative drivers and selection bias considered
- [ ] Measurable indicators and falsification conditions recorded
- [ ] Personal data handled safely; no doxxing or unnecessary identifiers
- [ ] Data and media reuse comply with source licenses

Disagreement is welcome; personal attacks, harassment, impersonation, unsupported accusations, and manipulated evidence are not. Reviewers can request changes or reject unverifiable submissions.
