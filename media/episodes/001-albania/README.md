# World Information — пилот видеопередачи: Албания

Статус: редакционная концепция, 27.11.2026; запись не назначена, выпуск не опубликован.

## Идея
Два собеседника с образованием в области международных отношений обсуждают одну страну через историю, современную политику, экономику и международные связи. Формат удалённого разговора с документальными вставками. Рабочее название: «Албания: одна нация, два государства и европейская мечта». Альтернативный заголовок: «Албания: Косово, протесты и европейское будущее». Не подразумевать, что объединение государств — общий политический выбор всех албанцев.

## Редакционная рамка
Не новостная сводка и не зачитывание сценария. Два равноправных ведущих; один открывает историко-региональный блок, другой — международно-политический, затем роли меняются. Различать наблюдения, заявления сторон, гипотезы и мнение ведущих. Не приписывать городам проживания или гражданству ведущих определённые политические позиции. Факты актуализировать перед записью и отметить дату среза в видео.

## Производство
1. Общий короткий бриф и таблица фактов: утверждение, ссылка, дата события, дата публикации, статус проверки, визуальный материал, лицензия. Каждый готовит 3–5 вопросов другому; выводы заранее не согласовывать.
2. Технический тест 5–10 минут: звук, кадр, свет, локальные дорожки. Запись не в прямом эфире. 1080p/25 или 30 fps одинаково у обоих, отдельные видео и аудио, 48 kHz при возможности. Наушники, камера на уровне глаз, уведомления отключены, резервная запись. Согласовать запись и публикацию.
3. Запись через Riverside (https://riverside.com/; отдельные локальные дорожки, ограничения тарифа проверить) либо привычный видеозвонок плюс локальная запись обоих через OBS (https://obsproject.com/) или штатную камеру. Хлопок/синхрометка в начале, каждый сохраняет оригинал; не полагаться только на запись звонка.
4. Автоматическая транскрипция русской речи Whisper (https://github.com/openai/whisper), желательно отдельно по дорожкам с приведением временных меток к общей шкале. Проверить имена, топонимы, числа, реплики и цитаты вручную. Черновая расшифровка с таймкодами -> редакторский монтажный лист -> монтаж -> финальные SRT/VTT и главы. Не переписывать смысл реплик без согласования.
5. Монтаж DaVinci Resolve или CapCut. Основная композиция — два ведущих; крупный план активного собеседника и полноэкранные документальные вставки по смыслу. Оригиналы и проект монтажа вне публичного GitHub.
6. Публикация после проверки обоими: полный выпуск YouTube, аудиоверсия при необходимости, 3–5 коротких фрагментов без искажения контекста, заметки и источники, текстовая версия. Использовать лицензированные/собственные визуалы; указывать автора, источник, лицензию, дату. Публиковать имена, биографии, сырые записи только с согласия обоих.
