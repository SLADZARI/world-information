# World Information — Dementor Lab

Open, collaborative laboratory for global signals, evidence-backed event analysis, causal hypotheses, and forecast tracking.

> **Status:** early public research project. Analyses are hypotheses unless supported by reproducible evidence. This is not a breaking-news verification service.

We study interactions among economics, politics, science, energy, logistics, ecology, technology, and society. Contributors can submit observations, competing interpretations, and measurable forecasts through pull requests.

Research principles: source everything; separate observations from causal claims; record uncertainty and counterevidence; retain revision history; distinguish event time from publication time; respect personal safety and source licenses.

This repository is being structured as an open research commons. The first working methodology will arrive through a reviewed pull request.
